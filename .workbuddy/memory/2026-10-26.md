## 项目分析：vueStay-trip（栖宿山海）

- 技术栈确认：Vue 3.5（`<script setup>`）+ Vite 8 + vue-router 5（hash 模式）+ Pinia 4（选项式 store）+ Vant 4（AutoImport/Components 自动按需引入）+ Axios 封装 + Less + postcss-px-to-viewport（375 设计稿） + dayjs + underscore + normalize.css。
- 数据来源：`http://codercba.com:1888/api`（coderwhy 教学接口），入口 `src/services/request/config.js`。
- 地图能力：index.html 全局引百度地图 JS API v4.0（ak 明文写在 html 中），用于详情页周边地图与首页 `BMap.Geolocation` 定位；搜索筛选 inherit 依赖。
- 业务模块：Home（banner/分类/热门建议/房源滚动分页）、Search（筛选条件 dropdown + 热门筛选 tabs）、Detail（轮播/信息/设施/房东/评论/须知/百度地图 + tabControl 滚动联动 + v-memo 优化）、City（van-index-bar 城市索引）、Order（按 type 切换订单列表）、Favor（收藏/历史）、Message。
- 工程亮点：自定义 `useScroll` 组合式函数（underscore throttle 节流 + 触底检测）、`smoothScrollTo` 缓动滚动、keep-alive include 白名单 + onActivated 恢复滚动位置、拦截器驱动的全局 loading。
