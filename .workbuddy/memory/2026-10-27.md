关键结论（后续复用）：
- 后端 `codercba.com:1888` **只支持 http**（https 返回 000），线上 https 页面直连会被浏览器按混合内容拦截，必须走同源 `/api` + 服务端代理；该接口 CORS 本身是放开的（回显 Origin）。
- 项目用 hash 路由，**不需要 SPA 回退规则**。
- Workers Builds 连接 GitHub 时，Dashboard 的 Worker 名必须等于 `wrangler.jsonc` 的 `name`，否则构建失败；Deploy command 默认 `npx wrangler deploy`，且会优先用 package.json 里的 wrangler 版本。
- 百度地图 AK 明文在 `index.html`，上线前需把 `*.workers.dev` 加入 Referer 白名单。

## 踩坑记录

- 用户跑 `npm run deploy` 报 `'wrangler' 不是内部或外部命令`：当初同步依赖用的是 `npm install --package-lock-only --ignore-scripts`，只写锁文件没装包。补跑一次 `npm install`（新增 32 包）后 `node_modules/.bin/wrangler` 就位，本地 `wrangler --version` = 4.153.0，`wrangler deploy --dry-run` 复验通过。
- 教训：往 package.json 加 CLI 类 devDependency 后，光更新 lock 不够，必须真正 install 一次才能写 `node_modules/.bin`，否则 npm scripts 里直接调用该命令会失败。
- 首次 `wrangler deploy` 会弹浏览器 OAuth 授权；无头/代理环境改用 `CLOUDFLARE_API_TOKEN` 环境变量。
- 构建日志里的 `postcss-px-to-viewport: postcss.plugin was deprecated` 是插件自身弃用警告，不影响产物。
